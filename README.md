An Intelligent Optimized Secure Blockchain Mechanism for Cloud Auditing
-----------------------------------------------------------------------

Built a cloud security system in Python that secures multimodal data (text, image, audio) on AWS S3 using AES-256 encryption and SHA-256 hashing, with an append-only SQLite blockchain storing immutable file fingerprints. Integrated the African Buffalo Optimization algorithm for continuous homomorphic monitoring to detect and block malicious nodes in real time. Implemented a key-matching audit mechanism that compares blockchain-stored hashes against live S3 file hashes to identify tampering and DoS attacks, achieving 100% confidential rate and sub-5ms encryption times.
